## 🚀 3 Passos Para Começar

### 1️⃣ Instalar

```bash
npm install @react-native-async-storage/async-storage
```

### 2️⃣ Configurar URL

Editar `src/services/api.js`:

```javascript
const API_URL = "http://seu-ip:3333";
```

### 3️⃣ Rodar

```bash
npm start
```
